## Cómo trabajamos

El software importa. El cómo, también. Cinco cosas que podés esperar de nosotros:

| | Principio | En la práctica |
|:--|:--|:--|
| **01** | **Ves el proyecto mientras se construye** | Alcance por escrito, hitos con fecha y un dashboard de métricas entregado con el MVP. |
| **02** | **No cobramos por hora** | Honorario cerrado por complejidad, equipo e impacto. La hora estima; no factura. |
| **03** | **No entregamos y desaparecemos** | Operación y mantenimiento desde el mes siguiente a la entrega. |
| **04** | **El código es tuyo** | Sistema, código y datos del cliente. Arquitectura independiente. Irte no cuesta nada. |
| **05** | **Expertos que usan IA, no al revés** | La IA acelera el trabajo. El criterio es humano y no se delega. |
